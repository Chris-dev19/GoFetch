# GoFetch

This is a very simple program to display system information in a beautiful way.

## Dependencies

- go

## Installation

To install gofetch onto your system, you can follow these steps:

- `$ git clone https://github.com/Chris-dev19/GoFetch`
- `$ cd GoFetch`
- `$ chmod +x install.sh`
- `$ ./install.sh`

or all commands in one:

`git clone https://github.com/Chris-dev19/GoFetch; cd GoFetch; go build -o gofetch; mkdir -p ~/.local/bin/; mv gofetch ~/.local/bin/`

## Usage

To run it, make sure ~/.local/bin/ has been added to your $PATH (e.g. in your .bash_profile).

`$ gofetch`
